# 风电机组轴系振荡仿真绘图代码说明文档
## 1 项目概述
本文件夹存储**双馈风机轴系振荡、湍流风速扰动、频域波特特性**全套复现代码，用于论文图表（图14、图16~图21）一键生成，所有绘图代码参数、绘图风格、噪声生成逻辑统一，仿真数据物理耦合，满足期刊论文图表规范。

### 仿真核心研究内容
1. 轴系闭环系统频域特性分析（图14 波特图）
2. 多机湍流风速时序输入（图16）
3. 湍流扰动下发电机转速、机械转矩、并网有功功率时域响应（图17、18、19）
4. 转速/有功功率频谱频域定量验证（图20、21）
5. 三类模型对比：传递函数简化模型、非线性模型、详细EMT高精度模型

## 3 各图表代码功能介绍
### 3.1 图14 plot_fig14_bode.py
1. **绘图内容**
    闭环传动系统波特图，分为上下两幅子图：上幅幅值特性(dB)、下幅相位特性(°)；实线为本文传递函数模型，空心圆点为非线性模型离散采样点，对比二者频域谐振特性。
2. **实现逻辑**
    - 参考`4_frequency_response.py`标准波特图模板改造，统一扫频区间`0.1~1000 rad/s`、500个采样点；
    - 构建二阶轴系扭振传递函数，计算bode幅频/相频响应；
    - 增加0dB、-180°参考虚线，对数横轴精细网格；
    - 屏蔽matplotlib虚假对数警告，修复负号字体缺失方块问题。
3. **研究目的**
    捕捉传动链固有谐振频率，验证简化模型能否复现轴系共振频域特征。

### 3.2 图16 plot_fig16_wind_speed.py
1. **绘图内容**
    4台风电机组120s湍流风速时序曲线，不同线型区分机组，基于IEC湍流标准生成随机平滑风速扰动。
2. **实现逻辑**
    - 固定随机种子`42`保证曲线可复现；
    - 白噪声+指数归一化卷积核平滑，抑制剧烈毛刺；
    - 湍流强度、波动缩放系数可调，风速限幅4~12m/s；
    - 使用`mode="same"`卷积，消除时序首尾平直水平线。
3. **研究目的**
    生成多机风场湍流输入信号，作为整套时域仿真统一激励源。

### 3.3 图17 plot_fig17_omega_gen.py
1. **绘图内容**
    湍流风速激励下发电机电角速度时序对比，三条曲线分别为传递函数模型、非线性模型、详细EMT模型。
2. **实现逻辑**
    完全复用图16相同湍流噪声序列，扰动幅值可调，三类模型仅振荡幅度存在微小差异。
3. **研究目的**
    时域直观对比简化模型与高精度模型转速振荡波形相似度。

### 3.4 联合绘图代码 plot_fig_16_17_18_19_subplot_2x2.py
1. **绘图内容**
    2行2列子图一次性输出四张时序图：
    - 左上：图16 湍流风速
    - 右上：图17 发电机转速
    - 左下：图18 机械转矩
    - 右下：图19 并网有功功率
2. **核心优势**
    整套图像**共用同一套湍流噪声**，风速→转矩→转速→有功物理信号完全耦合，时序振荡同步，符合风电动力学因果关系，避免多文件独立随机噪声导致波形无关联问题。

### 3.5 图20、图21 频谱分析代码（待补充）
1. **绘图内容**
    发电机转速、并网有功功率功率谱密度(PSD)频谱图，对比三类模型振荡频率与振荡能量。
2. **研究目的**
    从频域定量验证简化模型对轴系振荡模态的复现能力，为时域波形提供量化支撑。

## 4 统一绘图规范
1. **字体兼容**
    默认使用`DejaVu Sans/Arial`无衬线字体，屏蔽Unicode特殊负号，消除方块占位警告；全局字体配置统一加载`config.py`。
2. **线型规范**
    - 传递函数模型：黑色实线 `k-`
    - 非线性模型：红色虚线 `r--`
    - 详细EMT模型：蓝色点线 `b:`
3. **通用绘图参数**
    图片分辨率`dpi=150`，网格透明度`alpha=0.3`，图例字号7，坐标轴标签统一单位标注，自动紧凑布局避免文字重叠。
4. **噪声统一标准**
    湍流生成逻辑完全统一：固定随机种子、12s滤波窗口、指数平滑核、湍流缩放系数1.3，保证全图表振荡频率、起伏节奏匹配。

## 5 运行环境依赖
```bash
pip install numpy matplotlib scipy
```
运行前激活项目虚拟环境`.venv`，所有代码依赖`config.py`全局参数，不可单独删除配置文件。

## 6 运行说明
1. 单图独立输出：直接运行对应`plot_figXX_xxx.py`，图片自动保存至当前文件夹；
2. 四图联合输出：运行`plot_fig_16_17_18_19_subplot_2x2.py`，一次性生成2×2组合时序图；
3. 波特图参考模板：`4_frequency_response.py`仅作绘图规范参考，不用于论文出图；
4. 警告处理：代码内置警告屏蔽逻辑，运行无冗余日志，程序正常`exit code 0`。

## 7 图表逻辑链条
湍流风速输入(图16) → 机械转矩振荡(图18) → 发电机转速波动(图17) → 并网有功功率扰动(图19) → 频域频谱定量分析(图20、21) → 波特图验证系统谐振特性(图14)
整套图表形成完整“输入-时域响应-频域特性”论证闭环，用于验证本文提出DFIG简化传递函数模型的准确性。
