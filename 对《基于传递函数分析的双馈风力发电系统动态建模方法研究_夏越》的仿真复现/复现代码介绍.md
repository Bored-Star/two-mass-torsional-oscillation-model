# 风电逆变器谐波成因课题 | 仿真绘图代码说明文档
## 项目简介
本目录为**丁俐夫老师课题《风电逆变器谐波成因》**配套Python仿真绘图代码，用于论文图表一键复现。包含系统阶跃响应对比、频域波特特性、湍流风速时序、多物理量联合时域响应等绘图脚本。
全部脚本共享`config.py`统一参数与绘图风格，保证所有图片字体、分辨率、坐标轴规范统一，仿真工况保持一致，结果可完整复现。

## 二、各脚本功能详细说明
### 1. plot_fig11_pwr_speed.py 【论文图11】
- **输出文件**：`fig11_pwr_speed.png`
- **功能**：绘制有功功率与发电机转速对应关系曲线；
- **作用**：展示机组稳态运行工作点特性，作为小信号建模基础工况依据。

### 2. plot_fig12_step_response.py 【论文图12】
- **输出文件**：`fig12_step_response.png`
- **功能**：风速阶跃扰动下系统动态阶跃响应曲线；
- **作用**：初步验证系统动态特性，直观展示控制系统调节速度与超调特性。

### 3. plot_fig13_compare_ref14.py 【论文图13】
- **输出文件**：`fig13_compare_ref14.png`
- **功能**：不同模型动态响应对比曲线，作为图14频域特性的时域对照参考；
- **作用**：时域层面验证简化传递函数模型和高精度模型拟合程度。

### 4. plot_fig14_bode.py 【论文图14（正式版本）】
- **输出文件**：`fig14_bode.png`
- **功能**：绘制DFIG转速闭环控制系统波特图（幅频特性）；
- **实现**：构建系统完整闭环传递函数，对数扫频0.1~1000rad/s，对比多种模型频域谐振特征；
- **作用**：从频域分析系统谐振频率、稳定性，分析轴系振荡产生机理，是课题核心频域分析图表。

> ⚠️说明：运行代码内置警告屏蔽策略，消除matplotlib虚假log警告、负号字体缺失方块问题，不影响出图效果。

### 5. plot_fig16_wind_speed.py 【论文图16（独立绘图）】
- **输出文件**：`fig16_wind_speed.png`
- **功能**：生成多机组IEC标准湍流风速时序曲线；
- **作用**：为时域仿真提供统一随机扰动输入源，固定随机种子保证波形可复现。

### 6. plot_fig16_17_18_19.py 【图16~19联合绘图脚本】
- **输出文件**：`fig_16_17_18_2x2.png`
- **功能**：2行×2列联合子图，一次性绘制4条时序波形：
  - 图16：湍流风速
  - 图17：发电机转速波动
  - 图18：机械转矩振荡
  - 图19：并网有功功率波动
- **优势**：四张子图共用同一组湍流风速激励，严格满足风电动力学信号传递逻辑，避免多次随机生成造成波形不匹配。

## 三、运行环境与使用方法
### 依赖库
```bash
pip install numpy scipy matplotlib
```
### 运行步骤
1. 启动虚拟环境：`.venv\Scripts\activate`
2. 单独生成单张图：直接运行对应`plot_figXX_xxx.py`
3. 生成四图合并时序结果：运行`plot_fig16_17_18_19.py`
4. 所有脚本**依赖config.py**，请勿删除或移动该文件。

## 四、绘图统一规范
1. 全局字体统一配置，解决负号方块乱码问题；
2. 统一图片输出dpi=150，网格透明度、图例字号标准化；
3. 线型规范：传递函数模型、非线性模型、高精度模型使用固定线型区分；
4. 所有湍流时序仿真共用随机种子，保证全文仿真扰动一致，图表可以相互对照。
